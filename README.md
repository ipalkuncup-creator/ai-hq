- terms.html — Terms of Service
- privacy.html — Privacy Policy

Before publishing:
1. Replace [YOUR CONTACT EMAIL] in terms.html and privacy.html.
2. Create a public GitHub repository.
3. Upload these files to the repository root.
4. Enable GitHub Pages from Settings → Pages.
5. Use the resulting public website URL in TikTok Developer.
6. Keep the Terms of Service and Privacy Policy links visible on the homepage.

Important:
TikTok's current App Review Guidelines require a valid, externally facing official website with visible Terms and Privacy Policy links. URL ownership verification may also be required.
